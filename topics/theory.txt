2. key value mapping 
Python dictionary mein key-value mapping ke points:

3. Dictionary kya hai: Key-value pairs ka collection, curly braces {} mein
4. Key: Unique hoti hai, immutable honi chahiye (string, number, tuple)
5. Value: Kuch bhi ho sakti hai (number, string, list, dict, etc.), duplicate allowed
6. Mapping: Har key ek specific value ko point karti hai, jaise label → data
7. Ordered: Python 3.7+ mein insertion order maintain hota hai
8. Mutable: Banne ke baad add, update ya delete kar sakte ho
9. Fast lookup: Key se value turant mil jaati hai (hashing ki wajah se)
10. Duplicate keys: Agar same key dobara daalo toh purani value overwrite ho jaati hai
11. Access: Key se value milti hai; key na ho toh KeyError aata hai, .get() se safe access hota hai
12. Common operations: add/update, delete, check key exists, keys/values/items nikalna, loop karna
13. Use cases: Student → marks, product → price, word → meaning, config settings
